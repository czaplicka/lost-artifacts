Jak czytać wynik

  • OK przy stronie oznacza rozpoznany HTML oraz odpowiedzi bezpośrednich skryptów i arkuszy. Nie uruchamiamy formularza ani jego importów.
  • OK przy funkcji oznacza pozytywną odpowiedź na action: access dla bieżącego konta i adresu strony.
  • Brak katalogu w GitHubie nie dowodzi, że plików nie ma na hostingu lub funkcji nie wdrożono z lokalnego komputera.
  • Błąd sieci nie dowodzi braku funkcji. Może oznaczać CORS, problem połączenia albo limit czasu.
  • To nie jest test zapisu, grywalności ani poprawności wszystkich danych gry.
